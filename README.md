# Praetorian IQ Dashboard

The Praetorian IQ Intelligence Dashboard—a modern, responsive interface for intelligence gathering, assessment, and reporting.

## Design System

This dashboard implements the Praetorian design system with:

- **Colour palette**: Navy (#003E52), Copper (#B06533), grays
- **Typography**: Sora font family (Google Fonts)
- **Layout**: Flat design with top-border accent cards
- **Responsive**: Mobile-first design for all screen sizes

## Deployment

This is a static HTML application with no build step required.

### Deploy to Vercel

1. Push this repository to GitHub
2. Log into [Vercel](https://vercel.com)
3. Click "Add New Project"
4. Select your GitHub repository
5. Click "Deploy"

Vercel will automatically detect this as a static site and deploy it.

### Local Development

Simply open `index.html` in your browser to preview locally.

## Structure

- `index.html` — Complete dashboard application (single-file static site)

## Updates

To update the dashboard:
1. Edit `index.html`
2. Commit and push to GitHub
3. Vercel automatically redeploys
